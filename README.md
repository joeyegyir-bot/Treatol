# Treatol Ghana Limited

An elegant, responsive landing page for Treatol Ghana Limited — chemicals, fumigation and pest control from North Kaneshie, Accra.

## Preview locally

Serve the site from this folder (any static server):

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Contents

- `index.html` — the landing page
- `css/styles.css` — layout, type and colour
- `js/main.js` — navigation, contact form (WhatsApp / email)
- `assets/` — brand emblem, product photography and service images
